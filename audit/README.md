# OpenBayan Design & Theme Audit

- [**Complete Design & Color Audit Report (All Pages, Viewports & Themes)**](./DESIGN_AND_COLOR_AUDIT.md)

### Full Audit Scope Covered:
1. **Multi-Theme Audit Telemetry** across all 8 daisyUI themes (`emerald`, `retro`, `light`, `dark`, `night`, `corporate`, `winter`, `coffee`).
2. **All Routes & Surfaces** (`/`, `/search` with full/filtered/empty states, `/p/[id]` 0-JS permalinks, `CitationDrawer` live island).
3. **All Responsive Breakpoints** (Desktop `1706px`, Tablet `768px`, Mobile `390px`).
4. **Data & Rendering Bugs** (Raw `<span data-type='title'>` leaks, `<mark>` contrast failure in dark modes, permalink title contrast failure in retro).
5. **Visual Hierarchy & Reduction Filter** (Badge inflation, redundant CTAs, duplicate theme controllers).
6. **Responsive Layout Bugs** (Tablet 768px header button overflow & clipping, buried sidebar on `< 1024px`).
7. **Typography & Arabic Calligraphy Hierarchy** (`Amiri` and `IBM Plex Sans Arabic` mobile justification).
8. **Motion Principles & Easing** (Emil Kowalski / Jakub Krehel / Jhey Tompkins frameworks).
9. **Phased Implementation Plan** (Phase 1: Critical, Phase 2: Refinement, Phase 3: Polish).
