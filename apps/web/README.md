# OpenBayan Web Frontend (@openbayan/web)

Astro 5 SSR web frontend with Tailwind CSS v4, daisyUI 5, and React 19 client islands for the OpenBayan Classical Arabic Semantic Search & Scholarly Corpus Engine.

For complete project documentation, system architecture, data pipeline, and API specifications, please refer to the [Root README](../../README.md).

## Quickstart

```bash
# From workspace root
pnpm dev

# Or directly in this directory
pnpm run dev
```

- **Local Server**: [http://localhost:4321](http://localhost:4321)
- **Production Build**: `pnpm run build`
